# Jumpman Lives! — Strategy Guide

## How to Play

### Starting the Game

Run `JMAN2.EXE` in DOSBox. The game auto-detects your graphics hardware (VGA > EGA > CGA). You can override with command-line switches: `JMAN2.EXE /VGA`, `/EGA`, or `/CGA`. Add `/NOSOUND` to disable audio.

The main menu offers:

| Key | Action |
|-----|--------|
| **S** | Start game |
| **C** | Configure input device (keyboard / joystick) |
| **T** | Test input |
| **P** | Set number of players (1–4) |
| **E** | Level editor (registered version) |
| **H** | High scores |
| **R** | Story |
| **L** | Help |
| **D** | Credits |
| **O** | Ordering info |
| **Esc** | Quit |

### Game Mode Selection

After pressing **S** (Start), choose a level set:

| Choice | Set | Levels | End Bonus |
|--------|-----|--------|-----------|
| 1 | Jumpman | 1–12 (shareware: 1–2) | 100/life |
| 2 | Jumpman Jr | 13–27 | 250/life |
| 3 | Original | 28–45 | 500/life |
| 4 | All | 1–45 | 750/life |
| 5 | Random | Shuffled 45 levels, endless | 0 |

### Controls

| Key | Action |
|-----|--------|
| **Left/Right arrows** | Move left/right |
| **Up/Down arrows** | Climb up/down ladders and ropes |
| **Space** | Jump (hold direction for directional jump, press alone for straight-up jump) |
| **1–8** | Set game speed (1=fastest, 8=slowest) |
| **F1** | Pause |
| **Esc** | Pause / quit (confirm with Y) |
| **D** (during pause) | Save screenshot |
| **TAB ×4** (main menu) | Enable trainer mode (21 lives instead of 7) |
| **Backspace** (trainer mode) | Skip current level; hold **S** to save first |

### Objective

On each screen, collect every bomb/pellet (the glowing dots). When all are collected, the level is complete and the remaining time bonus is added to your score. Avoid hazards — falling too far, touching enemies, or being caught in explosions costs a life.

### Scoring

| Event | Points |
|-------|--------|
| Each pellet/bomb collected | 100 |
| Level completion time bonus | 0–1500 (decreases over time) |
| End-of-game bonus per remaining life | 100/250/500/750 (varies by mode) |
| Extra life | Every 10,000 points |

### Lives

- **Normal mode**: Start with 7 lives
- **Trainer mode** (TAB ×4 at menu): Start with 21 lives
- When all lives are lost, the game ends and high scores are recorded

## How to Win

### General Strategy

1. **Learn the speed system.** Speed 1 is very fast and gives the most bonus points (less time elapses), but speed 4–5 is more manageable for tricky platforming. Experiment with different speeds on different levels.

2. **Prioritise safety over speed early.** On unfamiliar levels, use speed 5–6 to learn the layout. Switch to speed 2–3 once you know the route to maximise your time bonus.

3. **Watch the bonus counter.** The bonus starts at 1500 and drops by 100 every few seconds. On most levels, you want to finish in under 15 seconds for a good bonus. Three levels (INVASION, DRAGON SLAYER, GUNFIGHTER) have no time bonus — take your time on those.

4. **Use the straight-up jump.** Pressing Space without a direction makes Jumpman jump straight up. This is essential for reaching pellets directly above you and for dodging hazards on the same platform.

5. **Understand falling.** If you walk off a platform without a ladder, Jumpman falls. A short fall is fine, but a long fall costs a life. Use directional jumps to cross gaps.

6. **Ladders vs. ropes.** Ladders are fixed; ropes and vines can be climbed but may have hazards. Green blocks can be pushed and sometimes create paths.

7. **Save every 5 levels.** The game prompts you to save every 5th level (unless in trainer mode). Always save — restarting from a save is far better than restarting from level 1.

8. **Use trainer mode to practice.** Press TAB 4 times at the main menu for 21 lives. This is built into the game — not a cheat — and lets you learn levels without the pressure of running out of lives. You can also skip levels with Backspace in trainer mode.

### Multiplayer

Up to 4 players can play, alternating turns. Each player has independent lives and score. When a player loses a life, the next player gets their turn. The game continues until all players are out of lives or all levels are completed.

## Level Maps

The levels are compiled into the executable as external object files (`scr##d.obj` for data, `scr##t.obj` for task logic). The level layouts are not stored in a directly readable format — they are binary sprite/dot arrays rendered by the game's `GenDraw` procedure.

Each level screen is 320×168 pixels (the playable area, with a status bar at the bottom). The coordinate system has (0,0) at the top-left. The player sprite is 32×32 pixels.

### Screen Layout

```
┌──────────────────────────────────────┐
│                                      │
│         PLAYABLE AREA                │
│         (320 × 168 pixels)           │
│                                      │
│                                      │
│                                      │
├──────────────────────────────────────┤
│  JUMPMEN = 07    LEVEL 01           │  ← Row 23 (y=184)
│  SCORE  0012500  PLAYER 1            │  ← Row 24 (y=192)
│  RUN SPEED 05    BONUS  001500       │  ← Row 24 (y=192)
└──────────────────────────────────────┘
```

- **JUMPMEN**: Remaining lives (2-digit display)
- **LEVEL**: Current level number (2-digit display)
- **RUN SPEED**: Current speed setting (2-digit display, 1–8)
- **PLAYER**: Current player number (1–4)
- **SCORE**: 7-digit score display
- **BONUS**: 7-digit remaining time bonus

### Movement Physics

- **Walking**: 4 pixels per tick horizontally (`x := x + 4*(right*2-1)`)
- **Jumping (directional)**: Uses `jp2` trajectory table — 24 steps of combined X/Y movement
- **Jumping (straight up)**: Uses `jp1` trajectory table — 21 steps of Y-only movement
- **Climbing**: 2 pixels per tick vertically on ladders
- **Falling**: 2 pixels per tick until landing
- **Screen bounds**: X must stay in range -5 to 309 (else `res := 0`, no movement)
- **Floor**: Y = `SCBOT` (8*21+4 = 172) is the bottom of the play area

## Using the Trainer

The trainer attaches to the DOSBox process and automatically locates the game's data segment — no manual value searching required.

### What the Trainer Can Do

- **Edit lives**: Set lives to any value (1–99)
- **Edit score**: Set score directly
- **Edit bonus**: Refill the time bonus to 1500
- **Edit speed**: Change game speed (1–8)
- **Edit level**: Jump to any level (1–45)
- **Enable trainer mode**: Toggle the built-in 21-lives mode without pressing TAB
- **Freeze lives**: Keep lives from decreasing
- **Freeze bonus**: Keep the time bonus from counting down
- **Max everything**: Set lives and bonus to maximum and enable trainer mode in one click

### Quick Start

1. Start Jumpman Lives! in DOSBox
2. Run the trainer and pick the DOSBox process
3. Click **Attach** — the trainer finds the game automatically
4. Use the fields and buttons on the **Live** tab to edit game state
